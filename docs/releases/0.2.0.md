# MediaForge 0.2.0

A local media workbench for images, video, audio, documents, data and QR codes. Open [MediaForge on the web](https://mediaforge-tau.vercel.app/) or choose a desktop download below.

## Changes

- Protect server networking from private-address fetches, DNS rebinding, unchecked redirects, arbitrary active-content responses and oversized buffered downloads. Retire unused URL import proxy.
- Remove randomized public download-provider discovery. Direct media links retain their actual type; platform links require an owner-configured trusted provider.
- Preserve CSV quoted fields, multiline cells and all JSON columns; parse nested YAML; reject invalid PDF ranges/reorders rather than silently discarding data.
- Allow the universal converter's displayed SVG option; generated SVG image files are raster-backed, not vector tracing.
- Make activity storage best-effort, normalize corrupt counters, defer download URL cleanup, preserve QR output format and retain feedback drafts when delivery fails.
- Keep the hardware-console identity while improving text contrast, keyboard focus/skip navigation, file-picker names, reduced-motion behavior and touch/keyboard region selection.
- Add Electron packaging, stable isolated profiles, loopback token protection, native smoke tests, cross-platform CI, checksums and separate manual draft-publication workflow.
- Update affected dependencies and document the remaining narrowly reviewed, expiring background-removal advisory.

## Packaging and support

Configured candidate formats: Linux x64 AppImage/deb, Windows x64 per-user NSIS installer, macOS arm64 and x64 dmg/zip. Only platforms with observed native smoke-test evidence may be advertised as verified. [Hosted verification](../hosted-verification.md) records passing native CI for all four targets; the original audit retains local Linux evidence and installation limits.

No auto-update service is configured. Back up the profile with the app closed and keep source media/downloads independently. Browser conversion drafts remain in memory and do not survive refresh/quit.

The owner selected **AGPL-3.0-only** and approved public 0.2.0 distribution on 8 November 2026. Matching source and third-party notices accompany this release. **Desktop builds are unsigned; macOS builds are not notarized.** Signing/notarization credentials were not supplied. The native CI matrix passed on Linux, Windows and both Mac architectures; this does not establish signed or notarized installers, privileged installation, or every device/codec. This release does not claim fully offline model/OCR first use, lossless Office layout conversion, secure PDF redaction/encryption/PDF-A, audio-preserving WebM conversion, or support for every browser codec.

## Download guide

- Windows x64: `.exe` per-user installer.
- macOS Apple Silicon: `mac-arm64.dmg` or ZIP; Intel: `mac-x64.dmg` or ZIP.
- Linux x64: AppImage or DEB. AppImage needs FUSE 2 and a compatible sandbox setup.
- `MediaForge-0.2.0-source.zip`: matching application source, lockfile/build scripts and the bundled AGPL library's original-source maps.
- `SHA256SUMS.txt`: verify every installer/source download. Native artifacts are rebuilt from the tagged release commit and verified again after upload.

No auto-updater is included. Installer execution, AppImage FUSE mounting and every device/codec are not certified by native launch smoke tests. Back up source media and keep exported files before replacing installations.
