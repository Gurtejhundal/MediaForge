# MediaForge 0.2.0 — release candidate

Status: **prepared locally; not publicly published**. See [release procedure](../releasing.md) and [verification audit](../audit.md) before changing this status.

## Changes

- Protect server networking from private-address fetches, DNS rebinding, unchecked redirects, arbitrary active-content responses and oversized buffered downloads. Retire unused URL import proxy.
- Remove randomized public download-provider discovery. Direct media links retain their actual type; platform links require an owner-configured trusted provider.
- Preserve CSV quoted fields, multiline cells and all JSON columns; parse nested YAML; reject invalid PDF ranges/reorders rather than silently discarding data.
- Allow the universal converter's displayed SVG option; generated SVG image files are raster-backed, not vector tracing.
- Make activity storage best-effort, normalize corrupt counters, defer download URL cleanup, preserve QR output format and retain feedback drafts when delivery fails.
- Keep the hardware-console identity while improving text contrast, keyboard focus/skip navigation, file-picker names, reduced-motion behavior and touch/keyboard region selection.
- Add Electron packaging, stable isolated profiles, loopback token protection, native smoke tests, cross-platform CI, checksums and separate manual draft-publication workflow.
- Update affected dependencies and document the remaining narrowly reviewed, expiring background-removal advisory.

## Packaging and support

Configured candidate formats: Linux x64 AppImage/deb, Windows x64 per-user NSIS installer, macOS arm64 and x64 dmg/zip. Only platforms with observed native smoke-test evidence may be advertised as verified. Local Linux evidence and current unverified targets are listed in the audit.

No auto-update service is configured. Back up the profile with the app closed and keep source media/downloads independently. Browser conversion drafts remain in memory and do not survive refresh/quit.

Public publication remains pending the owner’s project-license/distribution decision. Signing/notarization credentials were not supplied. Windows/macOS builds cannot be verified on this Linux host; the native CI matrix must pass before their artifacts can be included. This release does not claim fully offline model/OCR first use, lossless Office layout conversion, secure PDF redaction/encryption/PDF-A, audio-preserving WebM conversion, or support for every browser codec.
