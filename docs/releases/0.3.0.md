# MediaForge 0.3.0

This release finishes common file workflows: find a tool quickly, protect working files before leaving, resume image batches, and keep the soundtrack when exporting video.

- Search all 18 tools with a keyboard-accessible search box, result count and empty state.
- Working-file warnings cover internal links, refresh/close and supported browser history navigation. Desktop close offers Keep working or Leave and discard. Browser/OS termination can still discard memory-only work; there is no project autosave.
- Remember batch dimensions/quality/format, single-image conversion format/compression quality and video mute preference in localStorage. Image bytes, captions, QR contents, contact details and GPU tokens are not stored as preferences.
- Resume queued images and retry only failed images without replacing successful outputs. Resume/retry retains original batch settings; reprocessing everything asks before replacing results.
- Upscaling starts at 1080p with explicit larger sizes and accurately labeled 24/30 FPS sampling, avoiding an automatic 4K workload.
- Video conversion, upscaling and region blur preserve audio by default through Web Audio and MediaRecorder. Muting is optional. Exports remain real-time WebM, capped at 256 MB; keep the tab visible. Input/output codecs remain browser-dependent.
- Cancel video rendering, frame extraction, background-model work and OCR; partial outputs are not automatically saved. Background inference runs in a disposable worker. OCR cancellation during initial model setup can wait for that setup to finish before cleanup.
- Corrupt image crops show a persistent error and Choose another image action rather than an endless dimensions message.
- An Updates link opens the verified GitHub release page. Desktop installation remains manual; there is no automatic updater.
- Add an opt-in local NVIDIA companion connection inside the image cleanup tool. It binds only loopback, requires a fresh session token and approved origin, allows one bounded job and cleans temporary image files before responding. Selected images go to that local process. It does not provision cloud resources.

## Experimental GPU limits

NVIDIA CUDA is required for the optional image-regeneration engine. Plan for at least 12 GiB dedicated VRAM for initial trials, based on the upstream SDXL residency threshold. The verified minimum and full-pipeline fit remain unknown; the owner's 4 GB RTX 3050 is unverified. No real CUDA/model or official before/after SynthID trial was available here. Results are always labeled regenerated / SynthID unverified. Model downloads/licenses, latency and content fidelity require review. This is not advertised as verified invisible watermark removal. See the [local guide](../invisible-watermarks-local.md).

## Downloads and upgrades

Targets: Windows x64 installer, macOS Apple Silicon/Intel DMG and ZIP, Linux x64 AppImage/DEB. Native jobs must launch the packaged app and verify an export before producing candidates. Windows/macOS downloads remain unsigned; Mac builds are not notarized. Keep the Chromium sandbox enabled. Use the new installer for the same OS/architecture while preserving the application profile and exported files. Linux package name: `mediaforge-desktop`; Ubuntu App Center can uninstall it.

The separate Android 0.3.0 release uses the same updated tool source. It switches from the old preview certificate to a retained signing key. A one-time uninstall/reinstall is needed from Android 0.2.0; save exports first, since uninstall removes the app's private counters. Future upgrades require reuse of the retained keystore.

Release files have versioned names and SHA-256 checksums. Source archives match the tested release commit and retain the application/license and bundled AGPL dependency source. Existing 0.2.0 tags/assets are preserved. The existing time-limited Zod/background-removal dependency exception remains documented in [dependency review](../dependencies.md).
