## Observed checks

- Source lint, TypeScript and 22 unit tests pass. Production web and Android static builds pass.
- The complete current browser suite passes all 62 tests. CI reruns the suite before publication. Checks cover 20 routes, desktop/mobile widths, keyboard, reduced motion, populated exports, errors, repeated actions and activity persistence. They are not a claim that every codec/model works on every device.
- Four installed-APK tests pass with Wi-Fi and mobile data disabled on Android 15, AOSP WebView 124. Native picker imports a CSV; native destination dialogs save QR PNG, JSON, resized PNG, WAV, extracted PDF, batch ZIP and cropped PNG. Android's PDF renderer verifies two extracted pages. Other media fixtures are supplied to the renderer by the test harness; this does not prove every OEM picker/provider.
- Native lint and APK validation pass. The APK is signed using a development certificate and is not debuggable. All generated web files are checked against the packaged bytes. [CI](../.github/workflows/android.yml) gates publication on source/browser/APK/emulator checks and re-downloads draft release artifacts to verify checksums.
- [Real screenshots and GIF provenance](readme/README.md), [Android installation/storage/security guide](ANDROID.md), [Android release notes](releases/android-0.2.0.md).

## Limits retained

Physical ARM phones, Android 8–14/16 and OEM/cloud file providers were not available for local testing. Android 8 is a manifest minimum, not a certification; an updated WebView (Chromium 111+) is required. On-device model/OCR first-use downloads and every media codec are not verified on Android. Large media remains bounded by phone memory; exports are capped at 256 MB. URL downloads and optional feedback use their documented external web flows.

Invisible SynthID detection/removal is not implemented or verified. Cropping changes composition and cannot restore pixels hidden by a visible mark. No promise of defeating a hidden watermark is made.

Preview signing uses a development certificate; an owner-controlled persistent key is still needed for durable in-place upgrades. Reinstalling may clear local activity; saved exports remain ordinary files. Desktop 0.2.0 artifacts retain their original source and feature set; new web/Android features are not silently substituted into published desktop files.

The existing reviewed upstream Zod advisory chain remains documented in [dependency review](dependencies.md). The dependency gate accepts only the exact reviewed versions until the recorded exception expires; no new npm dependency was added. No secrets, signing keys, private media or production data are committed.
