## Observed local checks

- Lint, TypeScript and production build pass.
- 24 unit tests pass: conversion/data preservation, PDF page selection, network/desktop boundaries, Android export acknowledgments, cancellation, storage and release gates.
- The earlier 71-test suite passed. A later concurrent run caught a 4K recording timeout under host load; its exact scheduling cause was not established. Media tests now run serially, and the upscaler defaults to 1080p. The full 73-test serial suite passes, including background cancellation, invalid GPU selection and all video exports.
- A real background-removal model run completed on the CPU browser worker, returned a transparent PNG and emitted no page/console/network errors. This verifies execution, not segmentation quality for every photo.
- 29 Python adapter/HTTP tests pass locally with simulated hardware/engine results. The browser connects to an actual local companion for the no-CUDA failure path. Real GPU inference/detector checks remain unavailable.
- Packaged Linux x64 launches sandboxed, exports a PNG, blocks unauthenticated HTTP, preserves its origin/counters after restart and stops its child server on exit. Keep working in the native leave dialog preserves the QR output.
- Android static build, Gradle assembly/lint and APK byte/permission/signature checks pass. All four offline Android instrumentation journeys pass, including all 20 pages, Back → Keep working, native Save cancellation/retry, picker import, real PNG/WAV/PDF/ZIP contents, reopen/counter persistence and visible cropping. The first cold QR tap timed out; waiting for fonts and root hydration before native taps corrected the test, and the complete rerun passed. The local verification APK uses a temporary test certificate; publication must repeat these gates with the retained release certificate.
- Android signing bootstrap creates only encrypted backup/public fingerprint artifacts. A private temporary test proves recovery returns the identical keystore and password; existing public releases are preserved without generating another key, API failure/mismatched-source drafts reject rotation, and feature branches cannot bootstrap credentials. All four disposable signing/recovery regression tests pass.

## Limits

Working-file warnings are not autosave and cannot prevent OS termination. Browser history/refresh prompts depend on browser support and prior user interaction. OCR cancellation during initial worker/model setup can wait for that setup before cleanup. Local GPU Stop after current image does not instantly kill an active job. Model/runtime downloads need first-use connectivity. Browser media codecs and physical Android phones require device testing. Native smoke tests do not certify all installer paths, OS versions or AppImage FUSE setups. Windows/macOS installers are unsigned; macOS is not notarized. Updates are manual. The existing time-limited dependency advisory exception remains; [dependency policy](dependencies.md) passing does not mean zero advisories.

Final hosted build/release results, immutable source commit, hashes and deployed checks are recorded in the release verification record linked from the release notes after publication. Existing user profiles, source files, 0.2.0 releases and unrelated original-checkout changes are preserved.

## Native-gate follow-up

The first native matrix caught an early preference-edit race on macOS: edits before the hydration timer could fail to persist. Hydration now causes an explicit persistence render and never replaces an intervening user edit; its browser regression deliberately delays initialization. Windows/macOS also exposed a companion-start timeout. The listener no longer performs unnecessary reverse DNS for its fixed loopback address; a blocked-DNS regression verifies startup, and process-exit diagnostics now distinguish an interpreter failure from a timeout. The exact first CI timeout cause was not established from the original logs. Interpreter paths are explicit when CI supplies one.

The superseded Android run was cancelled before publication using an identity-checked, temporary CI maintenance job, then that job and its extra Actions permission were removed. No 0.3.0 assets were published from that source. Both publishers now refuse superseded main-branch source. Fresh native verification is required before publication; previous successes are not substituted for the corrected commit.
